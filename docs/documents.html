Measurements — build to these exactly

No folder metaphor, and no format icons

The seven categories are sections of one library rather than places a file sits, so nothing renders a folder. File format is text — "PDF · 1.2 MB" — which says more than a format glyph, since a glyph tells you nothing about whether the thing opens. No substituted icons, no inline SVG.

Resident library — findings first, then the seven in fixed order

Three findings, 1.3fr 1fr 1fr, gap 16px, never summed: expired (critical), expiring within 30 days (caution), and no expiry recorded at all (hatched). The third is not a milder version of the first two — it is the absence of the fact they are made of. Categories always render in the fixed order, iterated from the constant, never from the data. Legal and authority is first because a DNAR nobody can produce in ninety seconds is a DNAR that gets overridden. Category head 16px 24px 10px, title 15px/700, count 12px ink-500 beside it. Document row minmax(0,1fr) 13rem 13rem auto, gap 20px, padding 12px 24px. Name 14px/600, format and size 11.5px ink-500 beneath. Expiry chip: expired critical, expiring caution, in date plain text, does not expire plain text with who decided it, not recorded hatched. Somebody has to have said a document is permanent; an empty date field cannot say it. Filed-by column 11.5px ink-500 with the name at 600.

Empty is not always emptiness

A category with nothing in it renders "No documents" quietly, on bg-surface-sunken. A category another module's record implies should be non-empty renders the hatch instead, naming what is missing and where the expectation came from: "DNAR in place since 17/05/2025, and no document in Legal and authority." That is cross-module derivation, checkable from data rather than remembered.

A broken reference is a finding, not a dead link

Where another module carries a document id that resolves to nothing, the row renders hatched and unlinked with the id and where the reference came from. Never a link that fails on click, and never silence.

Organisation library

Coverage at the top with its denominator, and below the minimum population it renders Insufficient Evidence rather than a figure. Category rows minmax(0,1fr) 11rem 11rem 11rem auto — total, expiring, no expiry recorded — ordered by what expires soonest, not alphabetically, because the order is the finding.

Upload — subject first

560px drawer. The subject is the first thing on it and cannot be changed after a file is chosen: which resident, or which site. §2.4 on a screen whose whole purpose is attaching something to somebody. Expiry is answered before the file, and has no default — expires with a date, does not expire as a recorded decision, or leave it unrecorded and it renders as a gap afterwards. The file itself is not retrievable in this build and the drawer says so where the file is chosen, not afterwards in a toast. The metadata is a real in-memory add; the row will say the same thing. No fake download, no message saying stored.
