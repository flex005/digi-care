Measurements — build to these exactly

Eight reports, not fifteen

A screen whose only distinction is a name is a screen somebody has to learn for nothing. The seven that would have been a compliance check with a table under it are drill-downs from that check instead — which is also where a reader already is when the question occurs to them. The index says so where it would otherwise list them.

Index

Grouped by the question the report serves, not alphabetically. Row minmax(0,1fr) 15rem auto, gap 20px, padding 14px 24px. Name 15px/600, then what it answers at 12.5px ink-500 max 62ch — a report whose question cannot be stated in one line is a table looking for a purpose. Reports whose data is too thin are marked before you open them, hatched, saying how thin. Opening a report to discover it cannot say anything is a wasted trip, and this screen is where that is cheapest to prevent.

Report view — finding first, always

The finding renders above the filters and above the table, 20px 24px, figure 36px/800. Where the data is too thin the finding is that, in the hatched treatment, and the table still renders beneath it — refusing to render hides data somebody may still need, and the finding above is what stops the table being read as a conclusion. Same relationship the omissions banner has to the MAR grid: the finding states it, the table proves it. No ratings anywhere. Figures and coverage here; judgement stays on the compliance panel. A green rating on a report would reintroduce the reassurance the Dashboard refuses.

Filters and the restatement

Period first, then the cut, then the population. Beneath them, one line restating every figure below in terms of all three — Rule 3c, applied to a whole screen rather than one claim. Period comparison is a segmented control: this period, or this against the one before.

Table

Header 11px/700 uppercase on bg-surface-sunken. Body 12px 24px, numerics right-aligned at 700. A row below the population floor renders hatched with Insufficient Evidence in its figure cell, not a percentage — and it stays in the table, because removing it would make the table look complete. Change against the previous period is a figure with a direction word, never an arrow alone — 12px/700, critical when worse, positive when better, ink-500 when flat.

Per-staff reports carry a constraint the others do not

Workload and coverage, never a league table. Never sorted worst-first, always with the denominator that makes it meaningful — 3 omissions against 41 rounds worked is a different fact from 3 against 4. A note above the table saying plainly that a gap in a record is not necessarily a failure by whoever was on shift: a missed dose can be a broken trolley, a short round, or a resident in hospital nobody updated. This is the first screen in the build whose subject is a member of staff, and a figure about a person that does not carry what it is out of is an accusation rather than a measurement. Deactivated staff stay visible, marked, because records outlive access.

Export

No download control at all, as the inspection pack settled. A line saying what a real export would contain — this report, this period, this filter, this many rows — so a manager can plan around it. A button that produced nothing would be worse than its absence.
